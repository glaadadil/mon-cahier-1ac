# Mon Cahier — 1AC

Application web personnelle pour suivre les devoirs, réviser et consulter des fiches de cours (1ère année collège), avec un mode Élève et un mode Parent.

## Utilisation
Ouvrez `index.html` dans un navigateur, ou consultez la version en ligne via GitHub Pages.

Les données (tâches, humeurs, fiches de cours) sont enregistrées directement dans le navigateur de l'appareil (`localStorage`) — rien n'est envoyé sur un serveur.
